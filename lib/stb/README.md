# stb_image

This directory vendors `stb_image.h` v2.30 from the official `nothings/stb`
repository at commit `2c980bb59875b0d32144a71867fbdebb2f77cd20`.

Only JPEG support is compiled.  The project uses the header's MIT license
option, whose complete license notice is retained at the end of
`stb_image.h`.
