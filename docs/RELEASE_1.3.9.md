# Release 1.3.9 - Configurable Media Shortcuts

## Baseline

This incremental feature release applies to v1.3.8.

## Web-configurable shortcuts

The local management page now provides three Media Shortcut slots.  Each slot
accepts:

- a button label;
- a target `media_player` entity ID;
- a media content ID;
- a media content type.

All fields in a populated slot are required.  The entity must begin with
`media_player.` and must belong to the panel's configured Home Assistant area.
Shortcut configuration is saved to the existing SPIFFS `panel.json` file and
is returned by the authenticated configuration API.  Access tokens remain
write-only and continue to be stored separately in NVS.

## Current Home Assistant play-media payload

Version 1.3.9 updates all favorite and shortcut playback actions to use the
nested media structure generated by current Home Assistant releases:

```json
{
  "entity_id": "media_player.office_echo_studio",
  "media": {
    "media_content_id": "play my skiing playlist",
    "media_content_type": "AMAZON_MUSIC",
    "metadata": {}
  }
}
```

This matches the verified Amazon Music action for the Office Echo Studio while
remaining generic for other media-player integrations.

## Media dashboard layout

The existing bottom card now provides two independent rows:

- up to three configured Media Shortcuts;
- up to three automatically discovered Browse favorites.

Configured shortcuts therefore do not replace or consume the browse-media
results.  A shortcut remains visible but disabled if its target player is not
available in the configured area.

## Resource impact

Shortcut configuration uses fixed-size storage for three entries and adds no
new worker, task, framebuffer, artwork buffer, or network connection.  Actions
continue through the existing serialized Home Assistant worker queue.

## Upgrade options

- Apply `home_control_panel_v1.3.8_to_v1.3.9.patch` to v1.3.8 with
  `git apply`.
- Replace the project with the complete `home_control_panel_v1.3.9` release
  tree, preserving the local untracked `include/app_secrets.h` file.
